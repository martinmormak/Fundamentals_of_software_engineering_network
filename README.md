Network – Offline Social Network (Exercise Project)

This project was developed as part of the Fundamentals of Software Engineering – Network 2 course.

It is a class exercise assignment focused on implementing a simplified system inspired by a social network, designed to work in an offline environment.

The project simulates basic concepts of a social network such as users, interactions, and data management, but without requiring an active internet connection. It serves as a practical exercise for understanding how network-like systems can be modeled and structured in software engineering.

The main goal of the exercise was to practice software design principles, data handling, and system decomposition while working on a simplified “offline social network” concept.
